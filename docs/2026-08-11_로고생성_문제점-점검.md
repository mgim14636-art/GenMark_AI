## 🔴 서비스에 바로 영향

### 1. 심볼 안에 글자가 그려짐

프롬프트에 명시적으로 금지했는데도 모델이 영문 텍스트를 그립니다.

> Do not draw any letters, words, numbers, or typography of any kind —
> the brand name is added separately afterwards.

**실측**: `warm` 톤 4장 생성 중 1장에 `BEAUTY & N` / `Nd COSMETICS`가 렌더링됨.
그 아래 `logo_composer`가 합성한 "젠마크"가 또 있어 **글자가 두 겹**이 됨.

디퓨전 모델이 부정문을 잘 따르지 않는 전형적 사례. v1에서 심볼에 `G`가 박혔던
것과 같은 뿌리이며, v2에서 확률이 낮아졌을 뿐 사라지지 않았습니다.

**영향**: 브랜드명이 "젠마크"인데 로고에 "BEAUTY & N COSMETICS"가 박혀 나가면
사용자가 쓸 수 없는 시안입니다. 현재 걸러내는 장치가 없습니다.

**대응 후보**
1. 부정문 → 긍정문 전환 (`a purely pictorial mark composed only of shapes`).
   확률은 낮추지만 완전히 막지 못함
2. 생성 후 글자 검출 → 해당 시안 폐기 후 재생성. 확실하나 구현·비용 발생
3. 병행

**선행 과제**: 표본 4장으로는 실제 발생률을 알 수 없음. 12장 이상 측정 필요.

### 2. `num_variants` 상한 없음 → 비용 폭주

```python
# app/schemas/generation.py
num_variants: int = Field(4, ge=1, description="생성할 로고 시안 수")
```

최솟값만 있고 **최댓값이 없습니다.** 실행 확인 결과 `num_variants=100`이 검증을
통과합니다.

- OpenRouter flux.2-pro 과금: **메가픽셀당 $0.03**, 1:1 기준 장당 약 $0.03
- 100장 → **요청 1회에 약 $3.0**
- `ThreadPoolExecutor(max_workers=num_variants)` → **스레드 100개 동시 생성**

현재 백엔드가 4로 고정해 보내고 있어 실사고는 없지만, AI 서버 API가 열려 있는
한 언제든 발생 가능합니다.

**대응**: `Field(4, ge=1, le=8)` 정도로 상한. `max_workers`도 별도 상한.

### 3. 외부 API 에러 원문이 백엔드로 그대로 노출

```python
# app/api/routes/generation.py
except Exception as e:
    logger.error(f"Logo generation failed: {e}")
    raise HTTPException(status_code=500, detail=str(e))
```

`str(e)`에는 `flux_service`가 만든 메시지가 들어 있고, 그 안에 **OpenRouter 응답
본문이 통째로** 포함됩니다.

```python
raise RuntimeError(f"OpenRouter API 오류 ({response.status_code}): {response.text}")
```

**문제 두 가지**

- 응답 본문에 계정·요금·모델·제공자 정보가 섞여 나갈 수 있음
- 유사도 쪽은 `CodedHTTPException`으로 안정적인 `code` 체계를 잡아뒀는데
  **생성 쪽만 그 체계가 없음.** 백엔드가 실패 원인을 분류할 수 없어
  재시도 가능 여부조차 판단 못 함

**대응**: 유사도와 같은 방식으로 `GENERATION_*` 에러 코드 정의, 외부 응답 본문은
로그에만 남기고 응답에는 코드+요약만.

## 🟠 운영 안정성

### 4. 재시도에 백오프 없음

```python
for attempt in range(MAX_RETRIES + 1):
    ...
    if response.status_code >= 500 or response.status_code == 429:
        last_error = ...
        continue          # 즉시 재시도
```

429(rate limit)를 받아도 대기 없이 곧바로 다시 요청합니다. 4장을 동시에 보내는
구조라 429가 나기 쉬운데, 즉시 재시도는 상황을 악화시킵니다.

**대응**: `time.sleep(2 ** attempt)` 수준의 지수 백오프. `note_service`에 이미
같은 패턴이 구현돼 있어 참고 가능.

### 5. 부분 실패를 알리지 않음

4장 요청 → 2장 성공 시 **2장만 조용히 반환**합니다. 응답에 실패 정보가 없어
백엔드는 왜 2장인지 알 수 없고, 실패 사유(`errors` 리스트)는 버려집니다.

**대응**: 응답에 `requested` / `generated` 또는 `warnings` 추가.
브랜드킷 응답에 이미 `warnings` 패턴을 쓰고 있어 일관성 확보 가능.

### 6. `logger` 대신 `print` 사용

```python
# flux_service.py 72행, 136행
print(f"[flux_service]   단일 이미지 {...}s")
print(f"[flux_service] {len(variants)}/{num_variants} variants in {...}s")
```

컨테이너 로그 레벨 제어가 안 되고, 다른 모듈(`app.core.logging`)과 형식이 다릅니다.

## 🟡 문서-코드 정합성

### 7. 유사도 스키마의 `symbol` 허용 근거 부재

```python
# app/schemas/similarity.py
logoStyle: Literal["combination", "symbol"] = "combination"
```

그런데 `docs/api/ai-api.md` 실험 2의 결론은 이렇습니다.

> 데이터셋이 도형+문자 결합 상표(도형복합)로 구성되어 있어, 심볼 단독 쿼리는
> 레이아웃 불일치로 인한 오탐이 발생했습니다. (...) **유사도 분석 대상은 텍스트가
> 결합된 최종 로고로 한정합니다.**

워드마크·레터마크는 제외했으면서 **심볼을 왜 남겨뒀는지 근거가 문서에 없습니다.**
둘 중 하나입니다 — 근거가 있는데 안 적혔거나, 빼야 하는데 안 뺐거나.

### 8. 심볼 스타일은 텍스트 없이 유사도로 감

```python
def _wants_text_overlay(survey, style_key, brand_name):
    if style_key == "심볼" or not brand_name:
        return False
```

실행 확인:

| style | 텍스트 합성 |
|---|---|
| 심볼 | **False** |
| 혼합형 | True |
| 워드마크 | True |
| 레터마크 | True |

7번과 합쳐지면 **심볼 스타일 사용자는 구조적으로 오탐이 나오는 경로**입니다.

### 9. 워드마크·레터마크가 투명 배경

실행 확인: `compose_logo(..., style="워드마크")` 결과가 RGBA, 알파 최솟값 0
(완전 투명).

KIPRIS 상표 도면은 전부 흰 배경이라, 유사도 분석 전에 흰색 합성이 필요합니다.
`dino_service`가 처리하고는 있으나, **생성 단계에서 흰 배경으로 통일**하는 편이
경로가 늘어날 때 안전합니다.

## 🟢 세부 품질

### 10. 긴 브랜드명에서 글자가 초라해짐

캔버스 폭 1024 기준 실측입니다.

| 브랜드명 | 글자 높이 |
|---|---|
| 젠마크 | 217px |
| 젠마크코스메틱 | 201px |
| 주식회사 젠마크 코스메틱 랩러토리 | **155px** |

폭에 맞추려고 축소되는데, **줄바꿈이 없어** 무조건 한 줄로 밀어 넣습니다.
긴 이름일수록 심볼 대비 글자가 작아져 균형이 깨집니다.

### 11. 레터마크 이니셜 규칙 불일치

| 입력 | 결과 | 비고 |
|---|---|---|
| 젠마크 | `젠마` | 앞 두 글자 |
| GenMark | `GE` | 앞 두 글자 → **`GM`이 자연스러움** |
| Beauty Lab | `BL` | 단어별 첫 글자 |
| 가나다라마 | `가나` | 앞 두 글자 |

한글은 "앞 두 글자", 공백 있는 영문은 "단어 첫 글자"인데,
**공백 없는 영문(`GenMark`)은 대문자 기준이 아니라 앞 두 글자**로 처리됩니다.

### 12. 워드마크·레터마크만 `bold` 고정

```python
resolved_font_path = _resolve_font_path_for_call(font_path, "bold", tone, variant_index)
```

`b91a0b2`에서 톤별 폰트·자간(`light` 웨이트 포함)을 정비했는데,
**워드마크 경로만 `weight="bold"` 고정**이라 혜택을 받지 못합니다.
2026 트렌드상 가장 중요한 형식인데 가장 손을 덜 탔습니다.

### 13. `VALUE_MOTIF_BIAS` 미사용

```python
VALUE_MOTIF_BIAS = {
    "프리미엄": ["an abstract gem facet shape", "a radiant glow/sunburst shape", ...],
    "자연주의": ["a single botanical leaf silhouette", ...],
    ...
}
```

"프리미엄"을 고르면 보석·광채 계열이, "자연주의"면 식물 계열이 우선 나오게 하는
사전인데 **읽는 코드가 없습니다.** 현재 모티프는 브랜드명 유니코드 합으로만
결정돼, 선택한 가치와 무관합니다.

### 14. 텍스트 색을 심볼에서 추출

`_dominant_color(flattened, bg_rgb)`가 심볼의 대표색을 글자 색으로 씁니다.
v2처럼 가는 선 로고는 유효 픽셀이 적어 색 추출이 불안정할 수 있습니다.
(추정 — 실측 미실시)
